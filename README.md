# Time Capsule: AI-Powered Social Media App

### By Kiran Kumar Murahari

> _Preserving Today for the Eyes of Tomorrow_

## 📌 Overview

**Time Capsule** is an AI-powered social media platform designed to preserve, organize, and emotionally enhance users' digital memories—photos, videos, moods, and milestones. Unlike conventional social apps focused on real-time feeds, Time Capsule uses Artificial Intelligence to detect, curate, and revive emotionally significant memories intelligently over time.

---

## 🎯 Project Mission

To empower users to build emotionally intelligent time capsules by combining deep learning with modern memory storage systems—bridging past and present through personalized, secure, and AI-enhanced digital storytelling.

---

## 🔑 Key Features

- **AI-Enhanced Time Capsules**: Super-resolution, colorization, and age progression via GANs.
- **MoodAI Engine**: Detects user mood trends and generates personalized reflections.
- **Memory Vault**: A secure, user-controlled archive with future blockchain support.
- **Emotion-Based Retrieval**: Uses sentiment analysis and facial recognition to bring back meaningful moments.
- **AI Avatars**: Auto-generates avatars from user photos using image processing and GANs.

## 📚 How to Run

1. Clone this repository  
   `git clone https://github.com/YOUR_USERNAME/time-capsule-app.git`

2. Navigate to the backend folder  
   `cd backend && pip install -r requirements.txt`

3. Run the Flask server  
   `python app.py`

4. Navigate to the frontend folder  
   `cd backend && npm install && npm start`
