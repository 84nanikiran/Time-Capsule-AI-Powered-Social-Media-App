Time Capsule: AI-Powered Social Media App

By Kiran Kumar Murahari

Project Summary

Time Capsule is an AI-powered social media application that enables users to document, store, and relive memories through intelligent storytelling, emotional analysis, and advanced multimedia features.

Unique Features

  • AI-Enhanced Time Capsules: Super-resolution, colorization, and future-aged predictions using GANs.
  • Emotion-Driven Storytelling: Sentiment analysis and facial recognition to detect and resurface emotionally relevant memories.
  • Secure Memory Vault: Encrypted, user-controlled memory storage with blockchain potential for immutability.
  • MoodAI: Tracks user moods over time and generates intelligent insights based on emotional trends.
  • Interactive AI Avatars: Personalized digital avatars created using uploaded images and AI processing.

Sprint Objectives

  • Sprint 1: Build Minimal Viable Product (Account, Login, Landing, Story Pages)
  • Sprint 2: Develop Avatar Generator & Mood Tracking
  • Sprint 3: AI Integration (Sentiment Analysis + NLP)
  • Sprint 4: Optimize UX, add Testing, and Document API

Technology Stack

  • Frontend: React.js
  • Backend: Flask (Python)
  • Database: MongoDB
  • AI/ML: TensorFlow, Hugging Face Transformers
  • Deployment: GitHub, Visual Studio
  • Avatar Generation: GANs
  • Sentiment Analysis: Natural Language Processing (NLP)
